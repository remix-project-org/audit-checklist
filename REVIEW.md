# Review sheet: PR #1 items (Solidity compiler bugs, OpenZeppelin advisories)

This sheet lists every item this PR adds or changes, so reviewers can approve them one at a time. Items that need a decision come first.

**How to approve an item:** in `checklist.json`, set its `review_status` to `human_reviewed`, set `provenance.last_reviewed` to the review date, and put your name and decision in `review_notes` (e.g. `"Approved by <name>, <org>: severity raised to high"`). Edit any tag you disagree with in the same PR. Run `python scripts/validate.py` before pushing. Tools never set `human_reviewed`.

**What each item carries:** `vuln_category`, `severity_prior`, `applicability` (when the item applies; used to select items per contract), `detection_hint`, `verification`, `provenance`. Field definitions are in [SCHEMA.md](SCHEMA.md).
